# Meta - System Specs
TAGS: #Meta #Config

## Tag Registry

### Status
- #Active     : Currently working on
- #Done       : Completed
- #Someday    : Backlog / Incubation
- #Archived   : Cold storage

### Domain (Examples)
- #Dev        : Software development
- #Systems    : Low-level, OS, Architecture
- #Health     : Fitness, nutrition, logs
- #Finance    : Personal finances

### Type
- #Log        : Daily entries
- #Project    : Active projects (finite)
- #Area       : Ongoing responsibilities
- #Resource   : Reference material
- #Index      : Map of Content (MOC)

## Workflow
1. Capture in [inbox.md] or [5_Daily/YYYY-MM-DD.md].
2. Process inbox → Move notes to P.A.R.A folders.
3. Press 'F' on any #tag for global search.
4. Press 'gf' (go to file) to follow links.
